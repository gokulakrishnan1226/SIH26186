## Deploy to Render

1. Push this repo to GitHub
2. Go to **render.com → New → Web Service → connect repo**
3. Render will auto-detect [`render.yaml`](render.yaml) and use it
4. In the Render dashboard → **Environment**, add `GEMINI_API_KEY` if you have one
5. Deploy — your app will be live at `https://sentinel-ai.onrender.com` (or similar)

> **Note:** TensorFlow + OpenCV are large (~1.5 GB). Render's free tier has a 512 MB RAM limit — you'll need at minimum the **Starter plan ($7/mo)** for the model inference to work without OOM errors. The models (`face_model.h5`, `fer2013_mini_XCEPTION.hdf5`) and `models/` folder need to be committed to the repo (or downloaded at build time) since Render's filesystem is ephemeral. The existing [`app.py`](app.py:60) already auto-downloads the Caffe/YuNet weights on first run, so those are fine.
